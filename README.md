# OCR API для распознавания российских документов

REST API для распознавания текста и извлечения структурированных данных из изображений документов с использованием Tesseract OCR и машинного обучения.

## Возможности

- ✅ Распознавание текста из изображений (русский/английский)
- ✅ Автоматическое извлечение структурированных данных
- ✅ Поддержка 4 типов документов
- ✅ Автоматический подбор оптимальных параметров OCR
- ✅ Валидация и нормализация данных
- ✅ Предобработка изображений для улучшения качества
- ✅ REST API с документацией Swagger

## Поддерживаемые документы

| Документ | Извлекаемые поля |
|----------|------------------|
| **Паспорт РФ** | Серия/номер, ФИО, дата рождения, место рождения, дата выдачи, орган выдачи, пол, MRZ |
| **Миграционная карта** | Серия/номер, ФИО, гражданство, даты въезда/выезда, цель визита, пункт въезда, номер паспорта |
| **ИНН** | Номер ИНН (10/12 цифр), ФИО, дата рождения, дата выдачи |
| **СНИЛС** | Номер СНИЛС, ФИО, дата рождения, место рождения, пол, дата регистрации |

## Технический стек

- **FastAPI** - веб-фреймворк
- **Tesseract OCR 5.5** - OCR движок
- **Pillow** - обработка изображений
- **OpenCV** - предобработка изображений
- **Pydantic** - валидация данных
- **Docker** - контейнеризация

## Запуск

```bash
docker-compose up --build
```

API будет доступен по адресу: `http://localhost:8000`

**Swagger UI**: http://localhost:8000/docs

## Использование API

### Эндпоинт

**POST** `/api/ocr/upload-image?document_type={тип}`

**Параметры:**
- `document_type` (обязательный): `passport` | `migration_card` | `inn` | `snils`
- `file` (form-data): изображение документа

**Поддерживаемые форматы:** JPEG, PNG, BMP, TIFF, WEBP

### Пример запроса

```bash
curl -X POST "http://localhost:8000/api/ocr/upload-image?document_type=passport" \
     -F "file=@passport.jpg"
```

## Особенности реализации

### Автоматическая оптимизация
Система автоматически перебирает различные комбинации:
- Режимов предобработки (basic, aggressive, advanced)
- Page Segmentation Mode (PSM 3, 4, 6, 11, 12, 13)
- Выбирает лучший результат на основе количества извлечённых полей

### Валидация данных
- Проверка корректности дат (диапазоны, форматы)
- Автоисправление распространённых ошибок OCR
- Фильтрация служебных слов из ФИО
- Нормализация форматов данных
